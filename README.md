# Мобильное приложение «Граф Суворов»

**Руководство пользователя**

Добро пожаловать в документацию мобильного приложения для сотрудников кафе **«Граф Суворов»** (г. Суздаль).

Приложение автоматизирует процесс оформления, передачи и контроля выполнения заказов. Оно помогает официантам и сотрудникам кухни работать быстрее и без бумажной волокиты.

## Кому подходит это руководство

Документация предназначена для следующих сотрудников:
- **Официанты** — создают заказы и отправляют их на кухню.
- **Сотрудники кухни** — принимают заказы и отмечают готовность блюд.
- **Администраторы** — выдают доступы и управляют меню.
