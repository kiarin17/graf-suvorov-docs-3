# Роли пользователей

В приложении «Граф Суворов» существует две основные роли. Система определяет роль сотрудника автоматически после ввода логина и пароля.

## Официант

Официант работает с гостями и заказами.
- Выбирает столик.
- Создает и редактирует заказ.
- Отправляет заказ на кухню.
- Следит за статусом приготовления.

## Сотрудник кухни

Сотрудник кухни видит только те заказы, которые относятся к его цеху.
- Принимает заказ в работу.
- Меняет статус блюд (например, «Готовится»).
- Отмечает блюда как готовые.

Подробнее о процессе входа читайте на странице [Авторизация](authorization.md).
