# Частые вопросы

Здесь собраны ответы на самые популярные вопросы сотрудников.

### Не открывается нужный экран после входа
**Причина:** неверно определена роль.
**Решение:** проверьте, под каким логином вы вошли. Если роль указана неверно, обратитесь к администратору.

### Заказ не отправился на кухню
**Причина:** пропало интернет-соединение.
**Решение:** проверьте сеть. Заказ сохранится на сервере только после успешной отправки. Если связи нет, состав заказа останется в корзине.

### Можно ли удалить блюдо, если заказ уже отправлен?
Нет. После отправки заказ блокируется для изменений официантом. Если гость передумал, необходимо связаться с кухней.

### Как посмотреть историю своих заказов?
История доступна официанту в разделе «Заказы» на главном экране модуля.
